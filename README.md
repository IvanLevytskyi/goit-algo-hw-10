# Домашня робота до тем 9 та 10

## Опис домашнього завдання

### Завдання 1

Реалізуйте дві функції для видачі решти монетами з номіналами [50, 25, 10, 5, 2, 1]: `find_coins_greedy` на основі жадібного алгоритму та `find_min_coins` на основі динамічного програмування. Обидві функції мають приймати суму та повертати словник із номіналами монет і їх кількістю, наприклад для 113 - {50: 2, 10: 1, 2: 1, 1: 1}. Алгоритм динамічного програмування має знаходити мінімальну кількість монет. Порівняйте ефективність обох алгоритмів за часом виконання та складністю, особливо для великих сум. Результати та висновки додайте до readme.md.

### Завдання 2

Обчисліть визначений інтеграл за допомогою методу Монте-Карло. Перевірте отриманий результат, порівнявши його з точним аналітичним значенням або результатом функції quad. Проаналізуйте точність методу Монте-Карло та зробіть висновки.

## Результати і висновки

### Завдання 1

#### Складність

| Алгоритм | Складність |
| -------- | ---------- |
| Жадібний `find_coins_greedy` | O(n) |
| Динамічне програмування `find_min_coins` | O(S * n)|

тут n - кількість номіналів монет, а S - сума, яку потрібно видати

#### Час виконання для різних сум

| Сума | Жадібний (с) | Динамічне програмування (с) |
| ---: | -----------: | --------------------------: |
| 100 | 0.000000704 | 0.000160627 |
| 1 000 | 0.000000605 | 0.000865098 |
| 10 000 | 0.000000254 | 0.006352076 |
| 100 000 | 0.000000254 | 0.070588483 |
| 1 000 000 | 0.000000266 | 0.722864821 |

Замітка: час виконання для жадібного алгоритму відрізняється на дуже малі значення, хоча по суті виконується одинакова кількість обчислень. На результат можуть впливати планувальник ОС, кеш процесора, фонові процеси та інші фактори.

#### Висновки

Жадібний алгоритм значно ефективніший при великих сумах. Наприклад, для суми 1 000 000 час виконання жадібного алгоритму приблизно у 2 717 537 разів менший, ніж у алгоритму динамічного програмування. Така різниця виникає тому, що для фіксованого набору номіналів час роботи жадібного алгоритму практично не залежить від суми, тоді як час роботи алгоритму динамічного програмування лінійно залежить від неї. Перевагою алгоритму динамічного програмування є те, що він завжди знаходить оптимальне рішення, тоді як жадібний алгоритм не завжди гарантує оптимальний результат.

### Завдання 2

#### Результати

Функція для інтегрування: `x³ + x²`

Межі інтегрування: `[0, 2]`

Для методу Монте-Карло було вибрано прямокутник із шириною 2 та висотою 12.5. Кількість використаних випадкових точок - 5000.

| Метод інтегрування | Обчислене значення |
| ------------------ | -----------------: |
| Аналітичний        | 6.666666666666666  |
| SciPy              | 6.666666666666666  |
| Монте-Карло        | 6.819999999999999  |

#### Висновки

У моєму випадку (використання випадкових 5000 точок) метод Монте-Карло знаходить досить точне значення визначеного інтегралу. Отримане значення було порівняне із значеннями обчисленим аналітично та за допомогою бібліотеки SciPy. Абсолютна похибка інтегрування = | 6.819999999999999 - 6.666666666666666 | = 0.15333333333333332. Метод Монте-Карло грунтується на Законі великих чисел: зі збільшенням кількості випадкових вибірок результат наближається до точного значення. Водночас точність методу залежить від кількості вибірок, тому для складних задач може знадобитися дуже велика їх кількість.
